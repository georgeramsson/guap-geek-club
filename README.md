# 🌌 СОЗВЕЗДИЕ — Онлайн-запись на игры клуба ГУАП Geek Club

Официальный веб-сервис для анонсов и регистрации на настольные и ролевые игры клуба **«СОЗВЕЗДИЕ» (ГУАП Geek Club)**.

---

## 🎯 Решаемые задачи
* **Единый источник правды:** одна ссылка для постов во ВКонтакте и Telegram. Больше никакой путаницы с комментариями и подсчетом «плюсиков».
* **Живой учет мест:** счетчик свободных мест, списки участников и прогресс-бар в реальном времени.
* **Защита от овербукинга и перезаписи:** участники могут только занять свободное место, чужие записи защищены от редактирования.
* **Автоматический лист ожидания (резерв):** если места за столом закончились, желающие записываются в резерв. При отмене любого основного игрока первый из резерва автоматически переводится в основной состав.
* **Генератор постов для соцсетей:** мастер в один клик может скопировать красиво отформатированный текст анонса для публикации в ВК и Telegram.
* **Пуши в Telegram:** мгновенное уведомление в чат организаторов при каждой новой записи.
* **Фирменный стиль:** дизайн на основе официального брендбука клуба (глубокий космос со звездами, палитра `#6B0795` -> `#0B0741`, акценты `#FFFC1C` -> `#BB10F3` и пиксельный шрифт `PIXY`).

## 🚀 Быстрый старт на компьютере

Проект готов к запуску прямо «из коробки» без обязательной настройки внешних баз данных (встроен локальный автономный режим):

```bash
cd "pet projects/guap-geek-club"
npm run dev
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

* **Главная страница:** витрина карточек игр, фильтрация по системам (D&D, Ктулху, Настолки), кнопка быстрой записи.
* **Панель мастера:** [http://localhost:3000/admin](http://localhost:3000/admin) (Пин-код по умолчанию: `geek2026`).

## ☁️ Подключение облачной базы данных Supabase (Бесплатно)

Когда будете готовы выкатить проект в интернет на постоянную работу:

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (через GitHub за 1 минуту).
2. Нажмите **New project**, введите название (например, `guap-geek-club`) и выберите европейский регион (например, `Frankfurt`).
3. В панели проекта перейдите в **SQL Editor** в левом меню.
4. Откройте файл `supabase/schema.sql` из этого репозитория, скопируйте его содержимое, вставьте в редактор и нажмите кнопку **Run**.
   * Будут автоматически созданы таблицы `games`, `bookings`, индексы и правила безопасности (Row Level Security).
5. Перейдите в **Project Settings -> API** и скопируйте:
   * `Project URL`
   * `anon public key`
   * `service_role secret key`
6. Создайте файл `.env.local` в корне проекта (по образцу `.env.example`) и вставьте туда скопированные ключи:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-id.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
   SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOi...
   ```

## 🤖 Подключение Telegram-уведомлений в чат клуба

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram и создайте нового бота командой `/newbot`.
2. Скопируйте полученный токен в `.env.local`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
3. Добавьте бота в чат организаторов клуба и отправьте любое сообщение.
4. Чтобы узнать ID чата, откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   и найдите поле `"chat":{"id": -100xxxxxxxxxx}`.
5. Укажите этот ID в `.env.local`:
   ```env
   TELEGRAM_CHAT_ID=-100xxxxxxxxxx
   ```

## 🌐 Бесплатный деплой в интернет (Vercel)

1. Загрузите репозиторий на ваш GitHub.
2. Зайдите на [vercel.com](https://vercel.com) (логин через GitHub).
3. Нажмите **Add New... -> Project** и выберите репозиторий `guap-geek-club`.
4. В разделе **Environment Variables** добавьте переменные из вашего `.env.local` (ключи Supabase и Telegram).
5. Нажмите **Deploy**. Через 40 секунд у вас будет рабочий защищенный HTTPS-сайт, доступный из РФ без VPN!
